# 통화 녹음으로 챗봇 지식 쌓기 (갤럭시 폰 + 윈도우 PC)

코치님이 통화로 수강생이나 업체 질문에 답한 내용을 **「질문 → 답」 모음**으로 자동으로 쌓는 프로그램입니다.
쌓인 파일을 챗봇에 넣어 두면, 다른 수강생이 비슷한 걸 물었을 때 챗봇이 코치님 방식으로 답합니다.

```
폰 통화 녹음 → (Syncthing) → PC 녹음 폴더 → 받아쓰기(PC 안에서) → AI가 질문·답 정리 → 지식 폴더 → 챗봇
```

- 받아쓰기는 PC 안에서만 돕니다. 소리 파일은 밖으로 나가지 않습니다.
- AI 정리 단계에서는 받아쓴 글이 Claude API(Anthropic)로 갑니다.
- 수강생 이름, 업체명, 전화번호, 매출 같은 개인정보는 정리할 때 지웁니다. 다른 수강생이 챗봇에서 남의 정보를 보면 안 되기 때문입니다.
- 같은 질문이 또 나오면 새로 쌓지 않고 기존 답에 보탭니다.
- 잡담, 일정 잡기, 가족 통화처럼 답할 거리가 없는 통화는 버립니다.
- 받아쓴 원문은 남기지 않고, 처리가 끝난 녹음은 PC에서 지웁니다. 폰 원본은 그대로 남습니다.

준비물은 갤럭시 폰, 늘 켜 두는 윈도우 PC, Claude API 키(사용한 만큼 결제)입니다.

순서는 **A. 폰 녹음을 PC로 넘기기 → B. 프로그램 설치 → C. 실행 → D. 챗봇에 넣기**입니다.

---

## A. 폰 녹음을 PC로 넘기기

### A-1. 폰에서 통화 자동 녹음 켜기

1. 전화 앱 → 오른쪽 위 ⋮ → **설정** → **통화 녹음**
2. **통화 자동 녹음** 켜기 → **모든 통화**

녹음은 폰 `내장 저장공간/Recordings/Call` 폴더에 쌓입니다.

### A-2. PC에 Syncthing 설치

1. https://syncthing.net/downloads/ 에서 Windows 용을 받아 설치합니다.
   PowerShell을 쓸 줄 알면 `winget install Syncthing.Syncthing` 도 됩니다.
2. **윈도우 시작할 때 자동 실행**을 켭니다.
3. 브라우저에서 `http://127.0.0.1:8384` 가 열리면 설치된 것입니다.
4. 녹음 받을 폴더를 만듭니다: `C:\코치님-녹음`
5. PC가 절전으로 들어가면 녹음을 못 받습니다.
   **설정 → 시스템 → 전원 → 화면 및 절전** 에서 절전 모드를 **안 함**으로 둡니다. 화면은 꺼져도 됩니다.

### A-3. 폰에 Syncthing-Fork 설치

1. 플레이스토어에서 **Syncthing-Fork** 를 설치합니다.
2. 처음 켤 때 묻는 권한(저장공간 전체 접근, 알림, 배터리 최적화 제외)은 모두 허용합니다.

### A-4. 폰과 PC 연결

1. PC 화면(`127.0.0.1:8384`) → 오른쪽 위 **작업 → ID 표시** → QR 코드가 뜹니다.
2. 폰 Syncthing-Fork → **기기** 탭 → **+** → QR 스캔으로 PC를 추가합니다.
3. 잠시 뒤 PC 화면에 새 기기 연결 요청이 뜨면 **기기 추가**를 누릅니다.

### A-5. 폰 녹음 폴더 공유

1. 폰 Syncthing-Fork → **폴더** 탭 → **+**
2. 폴더 경로: `Recordings/Call`
3. 폴더 유형: **보내기 전용**
4. 공유 대상에 PC를 켜고 저장합니다.

### A-6. PC에서 공유 받기

1. PC 화면에 폴더 공유 요청이 뜨면 **추가**를 누릅니다.
2. **폴더 경로**를 `C:\코치님-녹음` 으로 바꿉니다.
3. **고급** 탭 → 폴더 유형 **받기 전용**. 이렇게 해야 PC에서 지워도 폰 원본이 남습니다.
4. 폰에 옛 녹음이 많으면 **무시 패턴** 탭에 아래를 넣어 최근 녹음만 받습니다.
   녹음 파일 이름 끝이 `YYMMDD_시분초` 꼴이라 날짜로 고르는 방식입니다.

   ```
   !*2611??_??????.*
   !*2612??_??????.*
   !*27????_??????.*
   !*28????_??????.*
   !*29????_??????.*
   *
   ```

   `2611` 은 2026년 11월입니다. 시작하는 달에 맞춰 위 두 줄 숫자를 바꿉니다.

### A-7. 폰 앱이 늘 돌게 하기 (제일 많이 막히는 곳)

이걸 안 하면 폰이 앱을 재워서 녹음이 하루씩 늦게 넘어옵니다.

Syncthing-Fork 설정의 **실행 조건**은 이렇게 맞춥니다.

- Wi-Fi에서 실행: **켬** (허락 칸이라 끄면 아예 안 돕니다)
- 모바일 데이터에서 실행: **켬**
- 충전 중일 때만 실행: **끔**
- 절전 모드 따르기: **끔**

배터리 설정도 두 군데 바꿉니다.

- 폰 설정 → 애플리케이션 → Syncthing-Fork → 배터리 → **제한 없음**
- 폰 설정 → 배터리 → 백그라운드 사용 제한 → Syncthing-Fork 를 **절전 예외 앱**에 넣기

### A-8. 넘어오는지 확인

아무 번호로 짧게 통화하고, 몇 분 안에 `C:\코치님-녹음` 에 파일이 생기는지 봅니다.
안 생기면 폰 Syncthing-Fork 첫 화면에 PC가 **연결됨**인지, PC가 절전에 들어가지 않았는지 봅니다.

## B. 프로그램 설치

프로그램은 GitHub 에서 받습니다. 아래 설명은 `C:\코치님지식` 에 받는 기준입니다.

**git 으로 받기(추천, 나중에 고친 판을 한 줄로 받을 수 있음)**

1. https://git-scm.com/download/win 에서 Git 을 설치합니다(설치 화면은 전부 기본값으로 다음).
2. `C:\` 에서 터미널을 열고 아래를 입력합니다.

   ```
   git clone https://github.com/anddl0523-tech/coach-call-kb.git 코치님지식
   ```

**git 없이 받기**: 저장소 화면 초록색 **Code** → **Download ZIP** → `C:\코치님지식` 에 풉니다.
이 방법은 고친 판이 나올 때마다 다시 받아 덮어써야 합니다(`settings.txt`, `.env`, `지식` 폴더는 덮어쓰지 마세요).

| 파일 | 하는 일 |
|---|---|
| `coach_calls.py` | 프로그램 본체 |
| `settings.example.txt` | 설정 견본. 처음 실행하면 `settings.txt` 로 복사되고, 고치는 건 `settings.txt` 입니다 |
| `.env.example` | API 키 넣는 견본 |
| `start.bat` | 실행 |
| `check.bat` | 설치가 다 됐는지 확인 |
| `requirements.txt` | 파이썬 부품 목록 |

### B-1. 파이썬

1. https://www.python.org/downloads/ 에서 최신 버전을 설치합니다.
2. 설치 첫 화면 아래 **Add python.exe to PATH** 에 꼭 체크합니다.
3. `C:\코치님지식` 폴더 빈 곳에서 Shift + 오른쪽 클릭 → **터미널에서 열기**, 그리고 아래를 입력합니다.

   ```
   py -m pip install -r requirements.txt
   ```

### B-2. ffmpeg (소리 파일 변환)

터미널에서 아래를 입력하고, 끝나면 터미널을 닫았다가 다시 엽니다.

```
winget install Gyan.FFmpeg
```

### B-3. whisper-cli (받아쓰기)

1. https://github.com/ggml-org/whisper.cpp/releases 에서 가장 최근 버전의 `whisper-bin-x64.zip` 을 받습니다.
2. `C:\whisper` 에 풀고, 그 안에서 `whisper-cli.exe` 를 찾습니다.
   하위 폴더(예: `Release`) 안에 있으면 그 폴더 안 파일을 전부 `C:\whisper` 로 옮깁니다.
3. 받아쓰기 모델을 받아 같은 폴더에 둡니다(약 1.6GB).
   https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
   → `C:\whisper\ggml-large-v3-turbo.bin`

PC가 느려서 10분 통화 받아쓰기가 10분 넘게 걸리면, 같은 곳에서 `ggml-small.bin`(약 470MB)을 받아 쓰세요.
정확도는 조금 떨어집니다. 이때는 settings.txt 의 `받아쓰기모델` 도 바꿉니다.

### B-4. Claude API 키

1. https://console.anthropic.com 가입 → **Billing** 에서 카드 등록과 충전
2. **API Keys** → **Create Key** → 나온 키를 복사합니다(다시 볼 수 없으니 바로 붙여넣기).
3. `.env.example` 을 메모장으로 열어 `여기에_API_키를_붙여넣기` 자리에 키를 붙이고,
   파일 이름을 `.env` 로 바꿔 저장합니다.

비용은 통화 1건에 수십 원에서, 지식이 많이 쌓인 뒤에는 수백 원 정도입니다(같은 질문인지 비교할 기존 지식이 늘어서). 콘솔 **Usage** 에서 쓴 만큼 볼 수 있습니다.
**Limits** 에서 월 사용 한도를 정해 두면 안심입니다.

### B-5. settings.txt 고치기

`check.bat` 을 한 번 더블클릭하면 `settings.txt` 가 생깁니다. 메모장으로 열어 필요한 줄만 고칩니다.

- `녹음폴더`, `whisper`, `받아쓰기모델`: 위 순서대로 했다면 그대로 둡니다.
- `제외`: 정리하면 안 되는 상대(가족 등)의 폰 연락처 이름을 쉼표로 적습니다. 예: `엄마,아빠,여보`
  이름이 녹음 파일 이름에 들어 있으면 받아쓰기도 하지 않고 넘깁니다.
- `코치님이름`, `분야`: 예를 들어 `분야=온라인 마케팅·상세페이지` 처럼 적으면 정리가 더 정확해집니다.
- `시작일`: 비우면 처음 켠 날 이후 통화만 정리합니다.

### B-6. 설치 확인

`check.bat` 을 더블클릭합니다. 모든 줄이 `[됨]` 이면 끝입니다.
`[안 됨]` 이 있으면 그 줄에 해당하는 B-1 ~ B-5 를 다시 봅니다.

## C. 실행

### C-1. 켜기

`start.bat` 을 더블클릭하면 검은 창이 뜹니다.

**처음 켤 때는 먼저 물어봅니다.** 통화에서 정리된 질문·답을 어느 챗봇에 넣을지(ChatGPT, Claude 프로젝트, 다른 챗봇),
직접 파일을 올릴지 자동으로 올라가게 할지 번호로 고릅니다. 답은 `settings.txt` 의 `챗봇`, `올리기` 줄에 남고 다음부터는 묻지 않습니다.
자동을 고르셨다면 그 답을 만들어 드린 분께 알려 주세요. 그 챗봇에 맞춰 자동 올리기를 붙여 드립니다.
「아직 안 정함」을 고르면 지식은 그대로 쌓이고, 다음에 켤 때 다시 묻습니다.

그다음부터는 1분마다 녹음 폴더를 봅니다.
창에 이런 줄이 찍히면 정상입니다.

```
받아쓰기 1532자 (95초): 통화 녹음 ○○○_261124_143012.m4a
지식 새로 2개 · 합침 1개: 통화 녹음 ○○○_261124_143012.m4a
```

창을 닫으면 멈춥니다. 같은 내용이 `기록.log` 에도 남습니다.

### C-2. PC 켤 때 자동으로 켜기

1. `Win + R` → `shell:startup` 입력 → 시작 프로그램 폴더가 열립니다.
2. `start.bat` 을 오른쪽 클릭 → **바로 가기 만들기** → 만든 바로 가기를 그 폴더로 옮깁니다.

### C-3. 처음 한 번 시험

1. 지인과 업무 상담처럼 짧게 통화합니다. 질문 하나, 답 하나 정도면 됩니다.
2. 몇 분 뒤 창에 `지식 새로 1개` 가 찍히고 `지식\전체.md` 가 생기면 성공입니다.
3. `실패:` 가 찍히면 그 줄 내용을 그대로 복사해 보내 주세요.
   (이 프로그램은 맥에서 시험을 마쳤고, 윈도우에서는 이 첫 통화가 첫 실행입니다.)

### 결과 파일

| 위치 | 내용 |
|---|---|
| `지식\전체.md` | 모든 질문·답을 주제별로 묶은 한 파일. 챗봇에 넣을 파일 |
| `지식\<주제>.md` | 주제별로 나눈 파일(예: `상세페이지 구성.md`) |
| `지식\질문답.json` | 원본 기록. **지우지 마세요.** md 파일은 이걸로 다시 만들어집니다 |
| `처리기록.json` | 어떤 녹음을 언제 어떻게 처리했는지 |
| `기록.log` | 실행 기록 |

정리된 답이 코치님 말과 다르면 `질문답.json` 에서 그 항목의 `answer` 를 고칩니다.
다음 통화가 정리될 때 md 파일에도 반영됩니다. md 파일을 직접 고치면 다음 정리 때 덮어씌워지니 json 쪽을 고쳐 주세요.

## 고친 판 받기

git 으로 받았다면 `C:\코치님지식` 에서 터미널을 열고 아래 한 줄이면 됩니다. 받은 뒤 `start.bat` 창을 닫았다가 다시 켭니다.

```
git pull
```

`settings.txt`, `.env`, `지식` 폴더, 처리 기록은 git 이 건드리지 않아서 그대로 남습니다.

---

## D. 챗봇에 넣기

`지식\전체.md` 를 챗봇 지식(자료) 칸에 올립니다.

- ChatGPT GPTs: GPT 편집 → **지식** → 파일 업로드
- Claude 프로젝트: 프로젝트 → **프로젝트 지식** → 파일 추가
- 다른 챗봇: 문서·FAQ 를 올리는 칸에 같은 파일을 올립니다.

지식이 쌓이면 일주일에 한 번쯤 새 `전체.md` 로 바꿔 올립니다.
챗봇 서비스가 정해지면 자동으로 올리는 부분을 붙일 수 있습니다.

---

## 주의

- 통화 녹음과 지식 파일에는 민감한 내용이 들어갈 수 있습니다. PC에 잠금 비밀번호를 걸어 두세요.
- `.env`(API 키)는 남에게 보내거나 인터넷에 올리지 마세요.
- 개인정보는 AI가 지우지만 놓칠 수도 있습니다. 챗봇에 올리기 전에 `전체.md` 를 한 번 훑어보세요.
- 통화 녹음을 상담 기록으로 쓴다는 점은 수강생에게 미리 알려 두는 편이 좋습니다.
